一、JS里正则的写法

    1.字面量  /规则/
    var reg = /^\d{11}$/;

    2.构造函数
    var reg = new RegExp("^\\d{11}$");

二、正则的使用   test()方法
    var reg = /^\d{11}$/;

    reg.test("13800138000");  // true
    reg.test("abc");          // false

三、正则基本符号
1.  abc    普通字符
2.  \d     数字0-9
3.  \w     字母、数字、下划线
4.  \s     空白字符：包括空格、Tap、换行
5.  .      任意字符，除了换行

四、数量词：控制出现几次
  符号：     含义：         例子：
  *         0 次或多次       /a*/ 匹配空、a、aa、aaa…
  +         1 次或多次       /a+/ 匹配 a、aa、aaa…
  ?         0 次或 1 次      /a?/ 匹配空或 a
  {n}       正好 n 次        /a{3}/ 匹配 aaa
  {n,}      至少 n 次        /a{3,}/ 匹配 aaa、aaaa…
  {n,m}     n 到 m 次        /a{2,4}/ 匹配 aa、aaa、aaaa

五、位置符号
  符号：          含义：
  ^            字符串开头
  $            字符串结尾

六、字符集
/[abc]/        表示 a、b、c 任意一个
/[0-9]/        表示 0-9 任意一个数字
/[a-z]/        表示 小写字母任意一个
/[A-Z]/        表示 大写字母任意一个
/[A-Za-z]/     表示 大小写字母任意一个
/[3-9]/        表示 3 到 9 任意一个
